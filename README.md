## 官网为什么不收支付宝：拒单的是 Stripe，不是你的卡

很多人看到"Your card was declined"，第一反应是卡余额不够或者卡被冻结。实际上大多数情况下，钱没扣、卡也没毛病。ChatGPT 订阅的收款由 Stripe 处理，它会综合账单地址、发卡行国家、IP 所在地做风控。“中国大陆发的卡 + 大陆网络环境”这种组合，基本会被直接判成高风险订单拒掉。刷十次拒十次，换一张国内卡结果也一样。

导致付款被拒的常见原因有这几类：

1. **国内卡 + 国内来源**——最高频也最难绕的一条，几乎没有调参空间。
2. **账单地址对不上**——卡是海外的，地址和邮编却随手填，Stripe 一校验就拒。
3. **网络环境“脏”**——注册、聊天、付款用了不同国家的共享节点，付款页要么一直转圈，要么直接报错。
4. **卡本身的限制**——不少充值型虚拟卡、预付卡不支持订阅类扣费；有些银行还会默认拦截境外订阅交易。
5. **短时间反复试错**——多次提交失败后，账号本身会被标成风险账号，之后再换好卡也照样被拒。

## 高频问题

**代充要给账号密码吗？充完要不要改密？**

不需要密码，正规代充也用不着你充完改密。反过来说，任何让你“交密码”或者“充完赶紧改密”的流程，恰恰说明那条路子本身不干净。

**官网付款被拒，会扣钱吗？**

正常不会。交易被拒说明没成功，钱不会真扣。偶尔出现预授权冻结，过几天会自动解冻退回，那也不是真扣款。

**账号还在订阅期内，能再办一次吗？**

不能叠加。多数平台付款前会核验账号状态，在期账号会被拦下、不会扣款，等当前订阅到期、账号回到普通状态再办。想换档位也不支持中途补差价，同样要等到期。

**到期后会自动扣款续费吗？**

代充一般没有自动续费。到期后账号自己变回 Free，需要续就再买一次。担心忘记的话，留意平台到期前的提醒邮件。

**Pro 能不能也用支付宝开？**

可以，逻辑一样。Pro 现在分 Pro 100、Pro 200、Pro 500 几档（9 月底刚改的名），用量依次更高，Pro 200 的用量大约是 Plus 的 10 倍。价格明显高于 Plus，支持的平台也更少，下单前看清页面标注的可售状态和处理时长。

**能开发票吗？**

看平台。有的平台能对已完成订单自助生成 PDF 商业付款凭证，报销够用；但它不等于国内增值税发票，公司流程走账前先问清楚。
